# Freela 🚀
**Sistem Informasi Pengelolaan Alur Kerja Klien dan Proyek untuk Freelancer**

Freela adalah aplikasi mobile berbasis Android yang dirancang khusus untuk membantu freelancer (seperti fotografer, videografer, desainer) dalam mengelola alur kerja pemesanan klien secara profesional, tertata, dan terpusat. Aplikasi ini menggantikan sistem pemesanan manual via chat menjadi sistem yang dinamis dan terintegrasi.

## ✨ Fitur Utama
* **🔐 Autentikasi Keamanan:** Sistem Login dan Register memastikan privasi data pemesanan klien aman dan tidak bocor ke pengguna lain.
* **📋 Katalog Jasa Dinamis:** Menampilkan daftar layanan (contoh: Liputan Wedding, Edit Video) yang datanya ditarik langsung dari database cloud, sehingga admin dapat menambah atau mengubah jasa tanpa harus update aplikasi.
* **🛒 Form Order Terintegrasi:** Klien dapat langsung mengisi formulir pemesanan jasa (nama, jadwal, alamat, dll) secara praktis.
* **⚡ Riwayat Pesanan Real-time:** Status pemesanan dan riwayat order akan langsung masuk dan tersimpan tanpa delay (real-time) antara klien dan admin.

## 🛠️ Teknologi yang Digunakan
* **Frontend:** Android Studio (Java & XML)
* **Backend / Database:** Firebase Realtime Database
* **Authentication:** Firebase Auth (Email & Password)
* **Architecture:** RecyclerView untuk optimalisasi list data dinamis.
